# 项目审查报告（2026-10-30 至 2026-10-31）

本文记录 2026-10-30 至 2026-10-31 的 RSS 插件审查、局部修复、回归结果与后续建议。已完成本地全量验证；报告区分已处理事项、保留行为、后续建议及真实环境验证边界。

## 已处理事项

- **文章读取与预览**：feed 详情通过 repository 的单条 JOIN 查询返回文章和 feed 标题；列表预览新增批量 JOIN 查询，避免逐篇调用 `article()`。查询保留按发布时间、更新时间、首次发现时间及序号排序的规则，并遵守预览和详情条数上限。
- **投递失败恢复**：多卡片投递保存可重用的卡片 payload 与幂等键。已发送成功的卡片在恢复时跳过；发送结果不确定的卡片进入 `unknown`，不自动重发；未处理卡片会释放 claim，避免消耗重试额度或停留在处理中。其他文章的失败、未知状态、退避时间和重试上限会阻止相关混合卡片被绕过。预发送错误依据剩余重试预算转入可重试或终止失败。
- **全量清理**：`data/cleanup` 的 `kind="all"` 执行统一维护流程，覆盖过期 cookie、插件媒体文件、平台媒体缓存、历史投递记录、测试记录、旧抓取日志、可清理文章和无引用 Telegraph 页面，同时保留原有计数结果。
- **维护任务可靠性**：后台维护循环记录阶段和异常类型，不写入异常正文；单轮维护失败不会终止调度或投递循环。
- **RSS 日期解析**：解析器从底层 feedparser 字典分别读取 `published` 和 `updated`，避免兼容属性把一个字段伪装成另一个字段。回归样本分别覆盖只提供发布时间或只提供更新时间的 XML。
- **日期筛选边界**：日期过滤拒绝 NaN 和无穷时间戳；无法表示的 `date_to` 日界（如 `9999-12-31`）返回输入错误。
- **抓取阶段异常记录**：调度器对抓取、错误结果记录、状态更新和持久化阶段的意外异常记录阶段与异常类型，不输出异常正文；失败仍更新源状态并继续队列处理，不生成不完整的抓取日志。
- **翻译可靠性与诊断**：翻译按长度上限分段并隔离单段失败；无效标记可在请求预算内二分重试；明确区分模型返回的 `SKIP` 与文本未变化。翻译结果和诊断包含状态、原因及段数，并持久化到投递记录和测试记录；渲染失败不会丢失测试历史，旧 v3 数据保持兼容。并发翻译会复用同一任务；一个等待者取消不会取消共享任务；运行时关闭会取消并清理翻译任务；缓存有界并按 LRU 淘汰，不缓存失败或不完整结果。主代理使用本地 fake harness 检查了消息列表/详情诊断和源详情到测试记录的重新进入流程，确认 `partial`、超时及段数信息可保留。

### 翻译问题的证据边界

旧实现存在已确认的代码缺陷：整篇文章只发起一次模型请求，标记异常可能导致整篇回退原文；缺少模型、请求异常等情况没有写入可供消息或管理界面查看的结构化诊断。本轮没有可供核对的真实失败文章或生产日志，因此不能据此断言任何一篇历史文章未翻译的具体原因。新增本地回归和 fake harness 验证了状态记录、持久化与界面读取，不等同于真实 provider 的端到端验收。
