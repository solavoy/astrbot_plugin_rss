# Plugin View API 契约

页面只通过已认证 AstrBot Plugin View 桥接访问 `/<plugin_name>/<endpoint>` 注册的 API，不自行携带令牌或启动 HTTP 服务。端点传给桥接时没有插件前缀、查询串或起始斜线；查询参数放 apiGet 第二参数，修改通过 apiPost。返回 plain business JSON，错误用 `error_response`，下载用 `file_response`。

以下为集成契约；实现时可以增加端点，不能让前端调用不存在的占位端点。详情字段直接来自数据库/运行态，不提供演示数据。

| GET endpoint             | 返回/查询                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| dashboard                | `counts`、近期文章/错误、`fetch_stats:{last_hour,failures,success_rate,curl_success_rate,browser_attempts,browser_fallbacks,cookie_hits,cookie_cache_hits}`、paused、scheduler状态和 `timezone`。`today_success` 按该时区当地午夜开始计算；近期文章最多10篇，按 `COALESCE(published_at,updated_at,first_seen_at) DESC,seq DESC` 排序。成功率按每个 Feed 的最终抓取结果计算；curl_success_rate 分母含浏览器回退任务，衡量最终 curl 结果，不是内部 HTTP 重试次数                           |
| feeds                    | q/page/page_size/scope；默认scope=all，scope=direct只展示存在直接订阅的Feed；每个Feed项包含 `translation_enabled`；items,total,page,page_size,timezone                                                                                                                                                                                                                                                                       |
| feeds/<feed_id>          | Feed（含 `translation_enabled`）、最新文章最多50篇、direct_subscribers、list_refs、fetch_logs、cookie_status、timezone；articles 按 `COALESCE(published_at,updated_at,first_seen_at) DESC,seq DESC` 排序                                                                                                                                                                                                                    |
| lists                    | q/page/page_size；items,total,timezone                                                                                                                                                                                                                                                                                                                                                                   |
| lists/<list_id>          | 列表、成员Feed状态、subscribers、最新文章最多100篇、timezone；articles 按 `COALESCE(published_at,updated_at,first_seen_at) DESC,seq DESC` 排序                                                                                                                                                                                                                                                                               |
| targets                  | 已登记目标数组；只来自真实聊天事件，不从普通命令参数构造身份                                                                                                                                                                                                                                                                                                                                                                          |
| deliveries               | page/page_size/status/platform/feed_id/list_id/target_id/date_from/date_to；items,total,timezone。日期输入 `YYYY-MM-DD` 按配置 IANA 时区的当地午夜筛选（date_to 含整天，内部使用次日午夜作为排他上界）；数字时间戳仍按 Unix 秒处理                                                                                                                                                                                                                       |
| deliveries/<delivery_id> | 文章、尝试记录、batch/card映射、平台message_id、渲染器和timezone                                                                                                                                                                                                                                                                                                                                                          |
| data/status              | `{database:{path,size_bytes,user_version,integrity},counts,cache:{sessions,media},scheduler,config:{general:{timezone,group_admin_only},fetch:{global_poll_interval,request_timeout},network:{proxy},rsshub:{default_url_prefix,rsshub_access_key},telegram:{telegraph_access_token},media:{send_as_media}},browser_compatibility,session_statuses}`；返回可见设置且敏感值脱敏，已配置的 `rsshub_access_key` 显示为“已配置”而非原值 |
| data/export              | 业务订阅JSON下载，保留Feed/列表/订阅启用状态及关系，无Cookie/Token；RSSHub 相对路由按原样导出                                                                                                                                                                                                                                                                                                                                           |
| data/backup              | SQLite一致快照下载，明确提示备份应保密                                                                                                                                                                                                                                                                                                                                                                                  |

| POST endpoint                    | 请求/行为                                                                                                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| scheduler                        | action=pause/resume/check；全局运行状态持久化                                                                                                                           |
| feeds/create                     | url,target_id,translation_enabled?；url 可为完整 HTTP(S) 地址或以 `/` 开头的相对路由；验证有效请求地址并建立直接订阅，目标必须为已登记目标；`translation_enabled` 为可选布尔值，默认 `false`                       |
| feeds/<feed_id>/update           | `enabled?`, `poll_interval?`, `translation_enabled?`；`translation_enabled` 为布尔值，省略时保持原值；间隔 0或null继承全局，正整数最小1秒，负数、小数或布尔值拒绝                                     |
| feeds/<feed_id>/refresh          | 手动强制抓取并遵守 HTTP 429 冷却；若请求等待期间同一源已有抓取完成，返回 `{feed_id,status:"skipped",reason:"concurrent_refresh"}`，不再重复请求                                                     |
| feeds/<feed_id>/unsubscribe      | target_id；只删除相应直接关系                                                                                                                                           |
| feeds/<feed_id>/preview          | target_id?；渲染预览，不发送；附带 timezone                                                                                                                               |
| feeds/<feed_id>/test             | target_id；显式测试推送，通过可靠队列记录操作                                                                                                                                   |
| lists/create                     | name,description?,poll_interval?；0或null继承全局                                                                                                                   |
| lists/<list_id>/update           | name?,description?,enabled?,poll_interval?；0或null继承全局                                                                                                         |
| lists/<list_id>/delete           | confirm=true；删除列表及自身关系，保留全局Feed和直接订阅                                                                                                                          |
| lists/<list_id>/members/add      | feed_id或url（完整 HTTP(S) 地址或 `/` 开头的相对路由）；允许批量条目，设置加入基线                                                                                                         |
| lists/<list_id>/members/remove   | feed_id；只删除成员关系                                                                                                                                               |
| lists/<list_id>/subscribe        | target_id                                                                                                                                                     |
| lists/<list_id>/unsubscribe      | target_id                                                                                                                                                     |
| lists/<list_id>/preview          | target_id?；最多预览跨成员源全局最新20篇，按 `COALESCE(published_at,updated_at,first_seen_at) DESC,seq DESC` 排序，全量正文按平台硬限预览；附带 timezone                                       |
| deliveries/<delivery_id>/retry   | 仅明确失败任务；success/unknown拒绝普通重试                                                                                                                                 |
| deliveries/<delivery_id>/resolve | confirm=true,resolution=delivered/retry；人工核对unknown                                                                                                           |
| data/import/confirm              | `confirm=true,filename,size`；绑定当前登录用户及文件名/大小，五分钟内一次有效                                                                                                         |
| data/import                      | 通过 `bridge.upload("data/import", file)` 上传；与有效确认匹配后校验 schema、完整 URL 或相对路由及所有Feed/列表关系并在单事务导入。相对路由保留其路由形式；目标只映射本机已登记目标，未登记目标通过`skipped_unregistered_targets`计数 |
| data/restore/confirm             | `confirm=true,filename,size`；绑定当前登录用户及文件名/大小，五分钟内一次有效                                                                                                         |
| data/restore                     | 通过 `bridge.upload("data/restore", file)` 上传；消费确认后暂停并关闭旧运行时、校验完整数据库schema/列/主键/唯一索引/外键、创建恢复前安全备份并重建运行时；失败会回滚并重启旧库                                              |
| data/cleanup                     | confirm=true,kind=articles/history/cookies/media；不得破坏未处理积压                                                                                                    |
| sessions/<session_id>/clear      | confirm=true；清除Cookie和browser profile                                                                                                                         |
| sessions/<session_id>/refresh    | 显式重建已允许公开来源会话，仍然拒绝交互验证                                                                                                                                        |

分页默认20，最大100。请求体限制、类型、长度、日期、URL和目标存在性需要后端验证。前端使用表单校验、加载/空态/错误提示及危险操作确认；所有来源HTML通过有序块纯文本/安全组件显示，不直接v-html。

群订阅命令默认允许群成员操作；`general.group_admin_only=true` 时，群内订阅/取消命令使用 `event.is_admin()` 验证 AstrBot 配置的管理员。管理面板请求必须带有效的 `request.username`。上传确认只在当前 WebAPI 运行周期内保留，绑定用户名、清理后的文件名和精确大小，并在成功上传后消费；重新加载插件会使未使用确认失效。管理面板不接受上传文件提供的平台身份。
